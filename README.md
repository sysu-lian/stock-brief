# stock-brief · 每天帮你看看自选股「有没有事」

> **先把最重要的话说在前面**
> 本工具只做**公开信息的整理与摘要**，帮你少漏看消息。
> **它不告诉你买什么、卖什么，不构成任何投资建议，也不是投资咨询服务。**
> 简报里的文字由你自己填入的大模型生成，不代表本站观点。投资有风险，决策请你自己判断、自己承担。

**一句话**：自选股十几只，公告和新闻根本看不过来？它替你每天过一遍，只回答「**今天有没有值得知道的事**」——而且**每句话都必须附原文链接，AI 编不出来源，这条结论就直接作废**。

🔗 **在线体验： <https://stock.chuanxi.fun>**（打开网页就能用，不用装任何东西）

> 不用申请密钥也能先玩：打开就能看示例简报；自己电脑上装了本地模型，还能零 Key 跑完整流程（见「本机零密钥试跑」）。

## 它到底帮我解决什么问题？

如果你有过下面这些时刻，这个工具就是为你做的：

- **自选股十几只，消息根本看不过来。** 财报、减持、中标、停牌、监管函……散在各处，一忙就漏了。
- **想用 AI 帮忙，但不敢信。** 问了 AI 一句"这公司最近有什么事"，它答得头头是道，你却不知道哪句是真、哪句是编的。
- **不想要"该买还是该卖"的答案。** 你只想先把事实看清楚，决定自己来做。
- **不想装软件、不想写代码、不想配一堆东西。** 最好是打开一个网页就能用。

它做的事很小，也很克制：**替你把消息筛一遍，把重要的挑出来，把出处一并给你。** 仅此而已。

## 和其他「AI 炒股」工具不一样在哪？

| 你在意的事 | 这里是怎么做的 |
|---|---|
| 会不会给我买卖建议？ | **不会。** 通篇不出现"建议买入 / 卖出 / 推荐"。它只说"发生了什么"，不说"你该怎么做"。 |
| AI 会不会瞎编？ | **有三道防线。** ① 摘要只能依据这次抓到的公告和新闻来写；② 结论后面必须附原文链接，你可以点开核对；③ 如果 AI 给不出链接，或者链接不是这次真实抓到的，**这条结论直接作废，不显示给你**。 |
| 会不会悄悄跳过、装作没事？ | **不会。** 数据没抓到、接口出问题，页面会明明白白告诉你哪里失败了，不会显示成"无重要事项"糊弄过去。 |
| 会不会碰我的股票账户？ | **完全不碰。** 它不连接券商、不需要你的账户密码、不看你的持仓、不下单。 |
| 会不会把我的信息存下来？ | 你填的密钥**用完就丢，不保存、不写日志、不回显在页面上**。 |

> 我们刻意把功能做得很小。少一个"给建议"的功能，对你反而更安全。

**如果你想要的是评分、买卖点、回测、多市场行情，或者让 AI 直接告诉你该怎么操作，
那这个项目不适合你。** 开源社区已经有成熟的同类工具，例如
[daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) 和
[TradingAgents](https://github.com/TauricResearch/TradingAgents)（它们提供评分、决策与回测等能力）。
这里只做一件事：把今天值得知道的消息、连同它的出处一起摆到你面前，判断留给你自己。

## 你会看到什么

下面是页面里默认的示例（**演示数据，仅用于展示排版，不代表真实行情，也不构成任何推荐**）：

```
📅 2026-11-10 股票简报（1 只）

🔴 中芯国际 688981  +1.2%
  摘要：公司发布三季度报告，营业收入同比增长。
  信息提示：无
  来源：https://…（演示占位链接）
```

- 🔴 **涨**　🟢 **跌**　⚪ **平盘或暂无行情**（按 A 股习惯，红涨绿跌）
- 颜色只表示涨跌；「无重要事项」用文字说明，不用颜色判断，避免混淆。
- 有事的股票，给你一句话说明 + 原文链接；没重要消息的，就老实写"无重要事项"，不硬凑内容。
- 点开"来源"就能看到原始公告或新闻，**请你自己核对一遍**——这是这个工具最想让你养成的习惯。

> ⚠️ 默认示例里的**中芯国际（A股 688981，科创板）**只是拿来演示界面，是一份固定的示例快照，不随实时行情变化，也**不是我们在推荐这只股票**。本项目目前只支持 A 股。

## 我需要准备什么？要花多少钱？

**运营方已经备好的**：行情、公告、新闻的数据接口。你不用申请、不用付费、不用配置。

**你需要自备的**：一个「大模型 API 密钥」。

用大白话解释一下它是什么：
> 现在各家 AI 公司（比如 DeepSeek、通义、Gemini）都开放了"让程序调用我"的接口。你去它官网注册、充值，它会给你一串很长的字符，那就是密钥。把它填进来，等于告诉网页"用我自己的额度帮我跑这次分析"。**钱是付给那家 AI 公司的，不是付给本站。**

**大概花多少？**
> 生成一份简报通常只花**几分钱甚至更少**，具体以你选的那家公司当时的定价为准。用多少付多少，不用包月。
> 你随时可以在那家公司的后台看到花了多少、也可以随时停用这个密钥，控制权完全在你手上。

**没有密钥怎么办？**
> 没关系，打开网页就能先看示例简报，先弄清楚它是什么、值不值得用，再决定要不要去拿一个。
> 如果你自己电脑上已经装了本地大模型，还可以**一分钱不花、不用申请任何密钥**地把完整流程跑一遍，
> 见后面的「本机零密钥试跑」。

### 3 分钟拿到密钥（照着做就行）

1. 挑一家你听过、信得过的 AI 公司，打开它的官网（DeepSeek / 通义 / Gemini 都可以，用哪家由你定）。
2. 注册账号，完成实名或手机验证。
3. 在后台找到「**API 密钥**」或「**开发者**」之类的入口，点「创建密钥」。
4. 复制那串字符（一般长这样 `sk-...`），粘到体验站的密钥框里。
5. 顺手充个几块钱就够试很久了；不想用了，回后台把密钥删掉即可。

> 站点里也放了对应的图解指引。**请妥善保管这串字符，不要发给任何人、不要发到群里。** 本站不会保存它。

## 你最可能担心的几件事

**Q：它会不会偷偷给我投资建议？**
不会。这是写死在代码里的边界：不做买卖建议、不做评分、不做"该不该买"。它连"看好 / 不看好"这类判断都不给。

**Q：AI 说的事我怎么敢信？**
这正是我们花最多力气的地方。每条结论都带原文链接；链接不是这次真实抓到的，这条就不显示；摘要里如果夹带了原文没有的内容，也会被拦下来。**宁可告诉你"信息不足，未生成摘要"，也不编一句给你看。**

**Q：我的股票账户、我的钱安全吗？**
它从头到尾不接触你的券商账户，不需要账号密码，不知道你持有什么，也不能下单。它只是读公开信息。

**Q：你们会保存我的密钥吗？**
不会。密钥只在生成这一次简报的过程中临时使用，用完即弃；不写进文件、不写日志、不显示在页面上。页面全程 HTTPS（浏览器地址栏那把小锁）传输。

**Q：我完全不懂技术，能用吗？**
能，这就是做这个网页的原因。日常使用只需要"打开网页 → 看 / 填 → 点生成"，不需要命令行、不需要装 Python。唯一稍稍陌生的是"密钥"，上面那 5 步就是为它写的。

**Q：数据全不全？会不会漏掉重要消息？**
公告直接来自交易所披露（巨潮资讯），正文也会被抓取用于摘要；新闻来自最近 24 小时的财经媒体；会明确列出抓到了哪些、没抓到哪些。**它不保证覆盖所有信息，所以每条都附了出处，重要决定请你以官方披露为准。** 数据源出问题时页面会报错，不会假装"今天没事"。

**Q：周末、放假会一直打扰我吗？**
不会。只在交易日收盘后生成；休市、节假日自动跳过，不推送。

**Q：手机上能看吗？**
能。网页适配手机；如果你想每天自动收到，可以走下面的推送方式，直接在手机里看。

## 我们明确不做的事

> 这不是"以后会做"，是**故意不做**。少做这些，是为了让它更可信、也更安全。

- ❌ 不给买卖建议、不做投资咨询、不做股票评分或推荐排序
- ❌ 不做回测、不管你的持仓、不做技术指标
- ❌ 只做 A 股，不做港股 / 美股
- ❌ 不做网页之外的复杂功能（社区、组合管理等）
- ❌ 数据来源挂了就明确报错，不偷偷换源、不硬凑结论

本项目**不是持牌证券投资咨询机构**，不提供任何投资咨询服务。

## 本机零密钥试跑（可选，进阶）

如果你电脑里已经装了本地大模型（例如 WorkBuddy 本机模型、llama.cpp、Ollama），
可以**完全不申请任何密钥、不花钱**把整条流程跑一遍，看看它到底怎么工作：

```bash
git clone <仓库地址>
cd stock-brief

LOCAL_DEMO=1 python -m src.main          # 直接在终端打印一份简报
LOCAL_DEMO=1 uvicorn web.app:app --port 8000   # 或打开网页 http://127.0.0.1:8000
```

网页里把「你用的是哪家 AI」选成「**本机模型（WorkBuddy）**」，密钥框**留空**即可。
核心引擎不依赖任何第三方库；只有开网页这一步需要装 `fastapi` 和 `uvicorn`。

> ⚠️ **这个模式只用于自己电脑上试用**：行情和公告是**固定示例数据，不是真实行情或新闻**，
> 简报里会明确标注；摘要则由你电脑上的模型真实生成。它不查交易日历、不推送企业微信。
> 在线体验站不会开这个模式，公开部署也请不要开。

## 自己部署（给懂技术的朋友 / 想每天自动收的人）

> 只想在网页上体验的话，**这一节可以整段跳过**。

```bash
git clone <仓库地址>
cd stock-brief
pip install -r requirements.txt
cp .env.example .env      # 填入你的大模型密钥、自选股列表等

python -m unittest discover -s tests -t . -v   # 先跑测试（不需要任何 Key）
python -m src.main                             # 定时推送版：本地跑一次
uvicorn web.app:app --port 8000                # WebUI 版：打开 http://localhost:8000
```

- WebUI 版只需在服务端配好数据通道（`TAVILY_API_KEY`）；大模型密钥由访客在页面临时填入，不落盘。
- 支持任意 OpenAI 兼容的 `/chat/completions` 接口（DeepSeek / 通义 / Gemini / 本机模型等），
  换 `base_url` + `model` 即可；**核心引擎用 Python 标准库发请求，不需要额外装大模型 SDK**。
- `.env` 与 `.venv` 已被 `.gitignore` 排除，密钥不会误提交。
- 定时推送用 GitHub Actions，交易日收盘后自动跑，休市自动跳过。
- 完整技术设计、数据契约、路线图与实现状态见 [`PLAN.md`](./PLAN.md)。
