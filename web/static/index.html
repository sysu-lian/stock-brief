我还没有密钥？3 分钟拿到（照着做就行）
  1. 挑一家你听过、信得过的 AI 公司（DeepSeek / 通义 / 其他均可），打开官网。
  2. 注册账号，完成手机或实名验证。
  3. 在后台找到「API 密钥」或「开发者」入口，点「创建密钥」。
  4. 复制那串字符，粘到上面的密钥框里。
  5. 顺手充几块钱就够试很久；不想用了，回后台把密钥删掉即可。用多少付多少，通常一份简报只花几分钱甚至更少，具体以厂商定价为准。
